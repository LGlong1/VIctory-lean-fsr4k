# Open pull requests of the forks we take from, reviewed for frame rate (2026-11-26)

Target: ray tracing off, a stable 30 fps (33 ms) at 8-10 GB private, RTX 3060 12 GB /
24 GB / i5-11400F. Where our frame goes (Series S opening cutscene): preparing
~110-170 ms (copies, refreshes), copy-back 25-80 ms, write-watch ~15 ms, waits for new
card memory to be mapped ~20 % of the run; the card itself is idle most of the frame.

## How they were picked

1,470 open PRs (avatarmanz 178, Marvisak 500+, fxceless 500+, DexNom 97, Belobug 195;
the API stops at 500). Every head fetched with git (`refs/prs/<remote>/<n>`), then kept
only those that change hot-path files (`host*`, `watch`, `shadow`, `list`, `inplace`,
`residency`, `texture`, ports, descriptors, xmem): 725. Of those, 175 quote measured
numbers in their messages; ray tracing, AMD, audio, docs, CI and tests set aside: 159.
Each shortlisted one checked against `nvidia` by patch id and by its `VICTORY_*` switches.
